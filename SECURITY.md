# Política de segurança

Relate vulnerabilidades em privado pela página de [Security Advisories do repositório](https://github.com/gmowses/fepublica/security/advisories/new). Não abra issue pública até haver uma correção ou uma data de divulgação combinada.

Inclua uma descrição do impacto, os passos mínimos para reproduzir e, se houver, uma prova de conceito. O mantenedor confirmará o recebimento e coordenará a divulgação pelo mesmo canal privado.

As provas de Merkle demonstram a integridade de um registro fornecido; elas não tornam inviável a tentativa de adivinhar identificadores de baixo espaço de busca. O campo `portador_cpf` nas projeções públicas é mascarado, mas registros canônicos e seus hashes são preservados para verificação de integridade.
